# Akarenga Package List for the Arduino Board Manager

This repo contains the `package_akarenga_index.json` used to add Akarenga OSHW
boards to the Arduino IDE, and hosts the core archives it points at.

## Source

- Core: https://github.com/akarenga-oshw/ArduinoCore-renesas
- Bootloader: https://github.com/akarenga-oshw/arduino-renesas-bootloader
